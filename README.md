# Sophie Bilynska Cosmetics — Atelier Storefront

Modern e-commerce storefront for **Sophie Bilynska Cosmetics** (Lviv, Ukraine).

- **Live Preview:** https://vic0803.github.io/sbcosmetics-atelier/
- **Stack:** Next.js 15 App Router · React 19 · TypeScript (`strict`) · Tailwind CSS v4 · `motion/react` · Local licensed `Futura PT`.

## Features
- 11 real products & 3 curated Atelier gift sets (`uk` / `en`)
- Clean editorial studio imagery + compressed `2.9 MB` hero video
- Interactive 4-step Skin Ritual Finder (`/quiz`) with 1-click full ritual add-to-bag
- Interactive Botanical Actives Library & Editorial Journal (`/journal`)
- Account cabinet with Apple / Google sign-in + required email onboarding step
- Cart drawer with free Nova Poshta shipping progress bar, promo code (`SOPHIE10`), and Checkout UI (`/checkout`)

## Local Development
```bash
npm install
npm run dev
```
